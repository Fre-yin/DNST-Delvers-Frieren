# Security Policy / Sicherheitsrichtlinie

## Deutsch

### Geltungsbereich

Diese Richtlinie gilt für Dungeon Settlers Delvers: Frieren und seine Pakete für MelonLoader und BepInEx. Frieren benötigt Delvers Core. Betrifft eine Meldung ausschließlich Core, nutze bitte die [Sicherheitsrichtlinie von Core](https://github.com/Fre-yin/DNST-Delvers-Core/security/policy).

Frieren ist eine Vorabversion. Sicherheitskorrekturen sind für die jeweils aktuelle veröffentlichte Version vorgesehen. Für ältere Versionen werden keine separaten Sicherheitsupdates zugesichert.

### Sicherheitslücken melden

Bitte melde vermutete Sicherheitslücken vertraulich über [GitHub: Report a vulnerability](https://github.com/Fre-yin/DNST-Delvers-Frieren/security/advisories/new). Erstelle dafür kein öffentliches Issue. Stimme die Veröffentlichung technischer Einzelheiten zuerst mit dem Maintainer ab, damit die Meldung geprüft und gegebenenfalls eine Korrektur vorbereitet werden kann.

Hilfreiche Angaben:

- Version von Frieren, Version von Core sowie Name und Version des betroffenen Loaders
- Version des Spiels oder Buildnummer bei Steam sowie Version von Windows, soweit relevant
- Beschreibung der möglichen Auswirkungen
- Schritte zur Reproduktion oder ein möglichst kleines Beispiel
- Bereinigte Protokolle oder Screenshots, falls hilfreich

Sende keine Passwörter, Zugangstokens, privaten Schlüssel oder persönlichen Spielstände. Entferne persönliche Daten aus Anhängen.

Das Projekt wird in der Freizeit betreut. Es gibt keine feste Frist für eine Antwort oder Behebung. Rückfragen, Bewertung und nächste Schritte werden über die vertrauliche Meldung auf GitHub besprochen.

Allgemeine Fehler und Funktionswünsche ohne Sicherheitsbezug gehören in die öffentlichen [Issues](https://github.com/Fre-yin/DNST-Delvers-Frieren/issues).

## English

### Scope

This policy applies to Dungeon Settlers Delvers: Frieren and its MelonLoader and BepInEx packages. Frieren requires Delvers Core. If a report concerns Core alone, use the [Core security policy](https://github.com/Fre-yin/DNST-Delvers-Core/security/policy).

Frieren is a prerelease. Security fixes are intended for the latest published version. Separate security updates for older versions are not guaranteed.

### Reporting a vulnerability

Please report suspected security vulnerabilities privately through [GitHub: Report a vulnerability](https://github.com/Fre-yin/DNST-Delvers-Frieren/security/advisories/new). Do not open a public issue. Coordinate disclosure of technical details with the maintainer first so the report can be investigated and, where needed, a fix prepared.

Useful information includes:

- Frieren and Core versions, plus the affected loader and its version
- Game version or Steam build and Windows version, where relevant
- Description of the potential impact
- Reproduction steps or a minimal example
- Sanitized logs or screenshots, if helpful

Do not send passwords, access tokens, private keys, or personal game saves. Remove personal information from attachments.

This project is maintained in spare time. Response and resolution times are not guaranteed. Questions, assessment, and next steps will be discussed through the private GitHub report.

General bugs and feature requests without security implications belong in public [Issues](https://github.com/Fre-yin/DNST-Delvers-Frieren/issues).
